# 彈珠賽場 Marble Derby

像賽馬一樣的彈珠博奕 H5 3D 網頁遊戲。
每場 10 顆彈珠衝下臥室裡的積木賽道，途中要通過七個障礙區：

1. **漏斗**：起跑後先進漏斗繞圈圈，洞口一次只過得了一顆，把擠成一團的彈珠拉成一條線
2. **十連發夾彎**：剛好一顆彈珠寬的木頭溝槽，連續十個 180 度急轉彎，只能排成一列過
3. **連續小漏斗**：三個小漏斗一個接一個，轉幾圈掉下去再進下一個
4. **旋轉十字**：三座會轉的十字門，運氣不好會被擋下來
5. **跳跳積木**：一列 4 塊大色塊積木鋪滿跑道，輪流升降，踩到會彈起來並加速。
   左邊有幾塊**金色積木**會閃光，亮著的時候被它彈到，就會飛過 U 字彎直接落到後面的賽道（抄近路）
6. **彈珠台**：一整片釘子，彈珠在裡面彈來彈去
7. **蹺蹺板塔**：一層層 V 字形的橘色蹺蹺板（像張開的翅膀）。彈珠掉在一邊翅膀上滾到中間，
   蹺蹺板往另一邊倒，彈珠從那邊翅膀尖端掉到下一層，左右左右往下，最後掉出去衝向終點

關卡之間幾乎沒有空跑道，一關接一關（參考 Fubeca's Marble Runs 的賽道節奏）。
開賽前選你看好的彈珠下注，然後看牠們比賽。前三名過終點就結算。

- **three.js**：3D 畫面（臥室場景、積木賽道、玻璃彈珠）
- **Rapier**：物理引擎（彈珠碰撞、滾動、旋轉橫桿）
- **Vite**：開發伺服器與打包

## 開始玩

```bash
npm install
npm run dev
```

打開終端機顯示的網址（預設 http://localhost:5173）。用 `--host` 啟動，所以同一個 Wi-Fi 下的手機也能用電腦 IP 連進來玩。

## 打包成單一檔案

```bash
npm run build
```

會輸出 `dist/index.html`，所有程式都包在這一個檔案裡，可以直接雙擊開啟，也可以上傳到 GitHub Pages、itch.io 等任何網頁空間。

## GitHub Pages

`.github/workflows/deploy.yml` 會在推到 `main` 時自動 build 並發佈 `dist/`。
第一次要到 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
（直接發佈原始碼是不能玩的：瀏覽器看不懂 `import 'three'`，一定要先 build。）

## 玩法

- 一開始有 💰 1000（存在瀏覽器裡），輸光會送 1000 救濟金
- 先選籌碼（10 / 50 / 100 / 500），再點彈珠旁邊的賠率按鈕下注，點越多次押越多
  - **獨贏**：押的彈珠跑第 1 名
  - **前三**：押的彈珠跑進前 3 名
- 賠率含本金：押 100、賠率 ×4.5，中了拿回 450
- 純運氣玩法：每顆彈珠的賠率一樣（獨贏 ×8.7、前三 ×2.9），莊家抽 12%

| 比賽中 | 按鈕 | 鍵盤 |
| --- | --- | --- |
| 切換跟隨的彈珠 | 👁 | F |
| 切換鏡頭（俯瞰全景 → 上帝視角 → 追尾） | 📷 | C |
| 快轉 1x / 2x / 3x / 5x（1x 已經是物理時間的 2 倍） | ⏩ | 空白鍵 |
| 轉視角 | 拖曳畫面 | |

音效全部用 WebAudio 即時合成：彈珠互撞是清脆的玻璃聲、撞到牆和積木是木頭聲，越用力越大聲，離鏡頭越遠越小聲；
跟隨的彈珠還有滾動聲，大力撞擊時鏡頭會輕輕晃一下。

手機如果覺得卡，網址後面加 `?fps`（例如 `https://.../ball/?fps`）會在左下角顯示每秒幾格和目前的畫質。
遊戲會自動調畫質：跑不動先降解析度，再不行就關掉陰影。

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/track.js` | 賽道產生器：用直線／轉彎／障礙區／漏斗／夾彎／蹺蹺板塔指令畫出中心線，產生 U 型軌道和七個障礙區 |
| `src/sim.js` | 物理世界（含旋轉十字、升降積木、釘子、漏斗、蹺蹺板）、比賽規則、AI 彈珠、撞擊偵測 |
| `src/odds.js` | 賠率計算 |
| `src/render.js` | 3D 畫面：臥室、積木柱、彈珠貼圖、鏡頭 |
| `src/main.js` | 主迴圈、下注、結算、HUD |
| `src/sound.js` | WebAudio 即時合成的音效（撞擊、滾動、蹺蹺板） |
| `test/headless.mjs` | 不開畫面跑一場，檢查賽道能不能跑完、每個障礙區花幾秒 |
| `test/calib.mjs` | 跑很多場記錄實力與名次，用來校準 `src/odds.js` 的係數 |

想改賽道，編輯 `src/track.js` 裡的 `PROGRAM`：

```js
['S', 40, 0.07],      // 直線 40 單位，坡度 0.07
['T', 90, 38, 0.06],  // 左轉 90 度，半徑 38（負角度 = 右轉）
['Z', 'pegs', 46, 0.2], // 障礙區（cross / piston / pegs），長 46，坡度 0.2
['F', 14, 5, 5],      // 漏斗：半徑 14、深 5、洞口下方落差 5
['H', 10, 7, 1.6, 0.2], // 連發夾彎：10 個彎、每段長 7、彎道半徑 1.6、坡度 0.2
['W', 5, 3.6],        // 蹺蹺板塔：5 層、每層間隔 3.6
```

改完跑 `npm run sim` 確認 AI 彈珠跑得完。
