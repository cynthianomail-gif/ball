# 彈珠賽場 Marble Derby

像賽馬一樣的彈珠博奕 H5 3D 網頁遊戲。
每場有一群彈珠衝下臥室裡的積木賽道，每過一個檢查點最後面的 20% 會被淘汰。
開賽前看實力、起跑排位和賠率，選你看好的彈珠下注，然後看牠們比賽。

- **three.js**：3D 畫面（臥室場景、積木賽道、玻璃彈珠）
- **Rapier**：物理引擎（彈珠碰撞、滾動、旋轉橫桿）
- **Vite**：開發伺服器與打包

## 開始玩

```bash
npm install
npm run dev
```

打開終端機顯示的網址（預設 http://localhost:5173）。用 `--host` 啟動，所以同一個 Wi-Fi 下的手機也能用電腦 IP 連進來玩。

## 打包成單一檔案

```bash
npm run build
```

會輸出 `dist/index.html`，所有程式都包在這一個檔案裡，可以直接雙擊開啟，也可以上傳到 GitHub Pages、itch.io 等任何網頁空間。

## GitHub Pages

`.github/workflows/deploy.yml` 會在推到 `main` 時自動 build 並發佈 `dist/`。
第一次要到 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
（直接發佈原始碼是不能玩的：瀏覽器看不懂 `import 'three'`，一定要先 build。）

## 玩法

- 一開始有 💰 1000（存在瀏覽器裡），輸光會送 1000 救濟金
- 先選籌碼（10 / 50 / 100 / 500），再點彈珠旁邊的賠率按鈕下注，點越多次押越多
  - **獨贏**：押的彈珠跑第 1 名
  - **前三**：押的彈珠跑進前 3 名
- 賠率含本金：押 100、賠率 ×4.5，中了拿回 450
- 賠率依彈珠實力（★）和起跑排位算出來，莊家抽 12%

| 比賽中 | 按鈕 | 鍵盤 |
| --- | --- | --- |
| 切換跟隨的彈珠 | 👁 | F |
| 切換鏡頭 | 📷 | C |
| 快轉 1x / 2x / 3x | ⏩ | 空白鍵 |
| 轉視角 | 拖曳畫面 | |

## 程式結構

| 檔案 | 內容 |
| --- | --- |
| `src/track.js` | 賽道產生器：用直線／轉彎／跳台指令畫出中心線，產生 U 型軌道、障礙物、檢查點 |
| `src/sim.js` | 物理世界、比賽規則（檢查點淘汰、升級卡）、AI 彈珠 |
| `src/odds.js` | 賠率計算 |
| `src/render.js` | 3D 畫面：臥室、積木柱、彈珠貼圖、鏡頭 |
| `src/main.js` | 主迴圈、下注、結算、HUD |
| `src/sound.js` | WebAudio 即時合成的音效 |
| `test/headless.mjs` | 不開畫面、全部由 AI 跑一場，檢查賽道能不能跑完 |
| `test/calib.mjs` | 跑很多場記錄實力與名次，用來校準 `src/odds.js` 的係數 |

想改賽道，編輯 `src/track.js` 裡的 `PROGRAM`：

```js
['S', 40, 0.07],      // 直線 40 單位，坡度 0.07
['T', 90, 38, 0.06],  // 左轉 90 度，半徑 38（負角度 = 右轉）
['J', 7],             // 跳台，缺口 7 單位
```

改完跑 `npm run sim` 確認 AI 彈珠跑得完。
